Beam Formula Reference

Cantilever · End Point Load
Supported
Mmax = P L
δmax = P L³ / (3 E I)
θmax = P L² / (2 E I)
Cantilever · Point Load at Position a
Supported
Mmax = P a
δfree end = P a²(3L − a) / (6 E I)
0 ≤ x ≤ a: δ(x) = P x²(3a − x) / (6 E I)
a ≤ x ≤ L: δ(x) = P a²(3x − a) / (6 E I)
Cantilever · UDL over Full Span
Reference only
Mmax = w L² / 2
δmax = w L⁴ / (8 E I)
θmax = w L³ / (6 E I)
Simply Supported · Midspan Point Load
Supported
R1 = R2 = P / 2
Mmax = P L / 4
δmax = P L³ / (48 E I)
Simply Supported · Point Load at Position a
Supported
R1 = P(L − a)/L, R2 = Pa/L
Mmax = Pa(L − a)/L
0 ≤ x ≤ a: δ(x) = Pbx[L² − b² − x²]/(6LEI)
a ≤ x ≤ L: δ(x) = Pa(L−x)[L² − a² − (L−x)²]/(6LEI)
최대 처짐 위치는 보 전체를 수치적으로 탐색합니다.
Simply Supported · UDL over Full Span
Reference only
R1 = R2 = wL/2
Mmax = wL²/8
δmax = 5wL⁴/(384EI)
Symbol legend
P: point load (N) · w: uniformly distributed load (N/mm) · L: beam length (mm) · a: load position from left/fixed end (mm) · b: remaining span = L − a (mm) · E: elastic modulus (MPa = N/mm²) · I: second moment of area (mm⁴) · Mmax: maximum bending moment · δmax: maximum deflection · θmax: maximum slope.
